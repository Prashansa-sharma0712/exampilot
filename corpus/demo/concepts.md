# Array

An array stores elements in indexed positions of a fixed-size sequence.

# Stack

A stack is a collection where the most recently added item is removed first.

# Queue

A queue is a collection where the earliest added item is removed first.

# Linked list

A linked list stores elements in nodes connected by references to other nodes.

# Binary search

Binary search repeatedly halves the search interval in an ordered collection.

# Merge sort

Merge sort divides a sequence into smaller sequences and merges sorted results.

# Hash table

A hash table uses a hash function to select a storage position for a key.

# Breadth-first search

Breadth-first search explores reachable vertices one distance level at a time.

# Depth-first search

Depth-first search explores one branch before returning to try another branch.

# Recursion

Recursion is a technique in which a function calls itself on a smaller problem.
